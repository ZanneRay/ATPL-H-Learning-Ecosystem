# Module 1 — Instructor Lesson Plan

> **Pilot lesson guide · 4 contact hours**  
> Aerodynamic Foundations & Building Rotor Lift

This is the instructor-facing run sheet for the Module 1 prototype. It converts the curriculum design into a sequence that another instructor should be able to deliver without having designed the module themselves.

!!! warning "Pilot status"
    This is a working lesson plan. Timing and activities should be tested in a real class before they become the delivery standard. Technical explanations must remain aligned with the approved Subject 082 source material.

## Lesson outcome

By the end of the session, given a local blade condition or simple changed condition, the student can predict and explain:

**local velocities → relative airflow → INFLOW/AOA → local aerodynamic forces → resolved components → rotor thrust / braking torque**

The central source-book practice is deliberately preserved: BET problems are reasoned through as **velocities → INFLOW/AOA → FL/FD → FV/FH → T/Mbrake**.

## Instructor preparation

Before class, confirm that students have access to the Module 1 pre-study and prepare:

- opening/final prediction sheet;
- blank blade-element sketch sheet or digital equivalent;
- the approved Module 1 visual sequence;
- HeliLab M1-01, M1-02 and M1-04, or static fallback visuals if a mission is not yet implemented;
- exit ticket;
- explanation rubric;
- timer/visible countdown for prediction tasks.

**Do not begin with a slide of learning objectives.** Begin with the helicopter problem.

# Run sheet

| Time | Phase | Instructor action | Student action | Evidence / decision |
|---|---|---|---|---|
| **00:00–00:03** | ORIENT | Show stable-hover visual. State only: rotor RPM constant; pilot raises collective. Ask the driving question. | Listen; no notes yet. | Problem established before theory. |
| **00:03–00:08** | PREDICT | Issue blank blade sketch. Ask: **“What changes first, and what happens next?”** Do not coach. | Draw and write individual causal chain. | Initial mental model captured. |
| **00:08–00:12** | COMMIT | Ask students to mark the first quantity they believe changes. Quick show of hands/poll only after sketches are frozen. | Commit publicly/privately. | D1–D4 misconception scan. |
| **00:12–00:15** | ORIENT | Show several different predictions without naming a winner. Say: “By the end of this lesson you must be able to decide which chain survives.” | Compare models. | Creates need for model. |
| **00:15–00:22** | BUILD | Introduce air as mass/inertia and density only to the depth needed for aerodynamic force. | Answer short prompts. | Can articulate why air can exert force. |
| **00:22–00:30** | PREDICT | Ask 50 m/s vs 100 m/s force tendency with coefficients/density held fixed. Collect ×2/×4 predictions. | Commit before equation reveal. | Tests intuitive v² reasoning. |
| **00:30–00:38** | BUILD | Reveal/use **q = ½ρv²**. Work the ratio, not a long numerical exercise. | Correct prediction and explain. | Dynamic-pressure relation established. |
| **00:38–00:45** | CHECK | Ask: “Where would density enter this model?” Brief density-altitude bridge; defer full performance treatment. | Point to ρ and state tendency. | Density has a location in causal model. |
| **00:45–00:52** | BUILD | Draw chord line and local relative airflow. Ask students to define AOA from the drawing before giving formal wording. | Annotate own sketch. | Reference geometry visible. |
| **00:52–01:00** | BUILD | Add AOI/pitch θ and distinguish it from α. Introduce inflow direction conceptually. | Compare θ and α. | D2 misconception targeted. |
| **01:00–01:07** | BUILD | Add FL perpendicular to vrel and FD opposite vrel. Ask “Is lift up?” | Answer relative to airflow. | D3 misconception targeted. |
| **01:07–01:15** | BUILD | Combine FL + FD → TAF. Do **not** call local FL rotor thrust. | Reconstruct vectors. | Local vs rotor-level distinction begins. |
| **01:15–01:22** | HELILAB MODEL | Run M1-01 Force Dependency. Freeze before each variable change and ask for prediction. | Predict, then observe. | Prediction → observation comparison. |
| **01:22–01:30** | HELILAB EXPLORE | Run M1-02 AOA ≠ pitch: change θ with flow fixed, then flow with θ fixed. | Explain how α can change in both cases. | Essential θ/α distinction demonstrated. |
| **01:30–01:35** | RETRIEVE | Remove visuals. Ask students to redraw chord, vrel, θ, α, FL, FD. | Individual retrieval. | Immediate reconstruction. |
| **01:35–01:40** | PEER CHECK | Reveal reference diagram. Students correct in another colour/state. | Self-correct + peer explain. | Errors remain visible. |
| **01:40–01:50** | BUILD | Show qualitative CL–α development. Ask what students expect as α rises. | Predict curve behaviour. | Existing stall model exposed. |
| **01:50–02:00** | BUILD | Explain separation at critical AOA and drag rise. Explicitly reject “stall = low speed” as complete explanation. | Write one causal sentence. | D6 misconception targeted. |
| **02:00–02:10** | HELILAB EXPLORE | M1-03 Stall Boundary. Pause before crossing modelled boundary. | Predict → test → explain. | Stall mechanism evidence. |
| **02:10–02:18** | TRANSITION | Show a rotor planform. Ask: “Does every point on this blade see the same speed?” | Predict root vs tip. | Need for local element model created. |
| **02:18–02:26** | BUILD | Introduce **vr = Ωr** qualitatively/quantitatively. Compare two radial stations. | Calculate/compare simple ratios. | Radial velocity model established. |
| **02:26–02:34** | BUILD | Add induced/axial velocity and construct local vrel vector. | Build velocity triangle. | Rotor-specific relative airflow established. |
| **02:34–02:40** | BUILD | Name inflow angle φ and establish **α = θ − φ**. | Explain equation in words. | Key BET relation established. |
| **02:40–02:48** | RETRIEVE | Blank screen. Give θ fixed, vi increased. Ask only: φ? α? | Individual arrows ↑/↓ + reason. | First rotor causal prediction. |
| **02:48–03:00** | BUILD | Assemble BET chain: velocities → angles → forces. Ask class to supply each next box before revealing it. | Co-construct chain. | Model built rather than shown whole. |
| **03:00–03:10** | BUILD | Resolve TAF into FV/FH and then Σ → T/Mbrake. Emphasise local → sum. | Complete causal chain. | D4 misconception targeted. |
| **03:10–03:13** | MISSION BRIEF | Explain M1-04 task and prediction gates. No demonstration of solution. | Prepare mission. | Avoids copying procedure. |
| **03:13–03:27** | HELILAB MISSION | Facilitate M1-04. Ask “what changes next?” rather than giving answers. | Complete prediction gates and causal chain. | Core mission evidence. |
| **03:27–03:30** | FREEZE | Stop interaction. Ask each student to write final rotor consequence and one uncertain link. | Commit final response. | Prevents endless slider search. |
| **03:30–03:38** | EXPLAIN | Pair students. Reviewer uses 4-point rubric cues. | 60–90 sec teach-back each. | Causal explanation evidence. |
| **03:38–03:43** | DEBRIEF | Select one strong chain and one plausible wrong chain. Diagnose links, not person. | Compare reasoning. | Error diagnosis modelled. |
| **03:43–03:48** | APPLY | Return original hover/collective problem. Students annotate original sheet. | Correct/add causal links. | Conceptual change visible. |
| **03:48–03:52** | TRANSFER | Add lower-density condition. Ask what stays the same and where ρ enters. | Predict tendency and justify. | Near-transfer evidence. |
| **03:52–03:58** | CHECK | Issue three-item exit ticket: reconstruct; increased vi with θ fixed; critique “low-speed stall”. | Individual, no notes. | Immediate mastery snapshot. |
| **03:58–04:00** | REFLECT | Repeat confidence rating. Preview: later modules change the BET inputs and boundary conditions. | Rate + one-sentence reflection. | Closes model, opens future learning. |

# Instructor visual sequence

The lesson should be built around a small set of reusable figures rather than a conventional high-slide-count lecture deck.

| Visual | Purpose | Reveal strategy |
|---|---|---|
| **V01 Stable hover + collective input** | opening problem | show aircraft/context only |
| **V02 Air has mass / force bridge** | air inertia | simple conceptual visual |
| **V03 q = ½ρv² relationship** | velocity/density force dependency | reveal after prediction |
| **V04 Local aerofoil reference frame** | chord + vrel | build progressively |
| **V05 θ versus α** | misconception correction | overlay θ, then α |
| **V06 FL / FD / TAF** | force geometry | vectors appear sequentially |
| **V07 CL vs α / separation** | stall mechanism | reveal curve after prediction |
| **V08 Rotor radial stations** | need for blade elements | compare root/outboard |
| **V09 vr = Ωr** | rotational velocity | animate radial dependency if possible |
| **V10 Velocity triangle** | vrel + φ | construct vectors, not pre-completed |
| **V11 α = θ − φ** | BET angle relationship | connect directly to V10 |
| **V12 Section-force resolution** | FV / FH | show TAF then components |
| **V13 Local → whole rotor** | summation | repeated blade elements → Σ |
| **V14 Complete BET causal chain** | integration | students supply missing nodes |
| **V15 Original vs revised hover explanation** | conceptual change | end-of-lesson comparison |

**Production rule:** V04–V14 should share the same symbols, arrow directions, terminology and visual grammar. Students should not have to relearn the diagram language between slides, handbook and HeliLab.

# Exact core prompts

Use these consistently during the pilot so the learning design can be evaluated rather than changing with instructor improvisation.

### P1 · Opening

> **The helicopter is established in a stable hover. Rotor RPM remains constant. The pilot raises collective. At one blade element, what changes first — and what happens next?**

### P2 · Velocity dependency

> **If local relative-airflow speed doubles while density, area and aerodynamic coefficients are held fixed, what happens to the aerodynamic-force tendency? Commit before calculating.**

### P3 · AOA distinction

> **Can AOA change while blade pitch/AOI remains constant? If yes, what must have changed?**

### P4 · Rotor radial dependency

> **At constant rotor angular speed, which blade element has the greater rotational velocity: one near the root or one farther outboard? Explain without using the lift equation yet.**

### P5 · Inflow transfer

> **Blade pitch θ remains constant and the upward/axial component of local relative airflow increases. What happens first to inflow angle φ, and what does that do to effective AOA α?**

### P6 · End-of-module transfer

> **Return to the opening collective problem. Now reduce air density substantially. Which causal links remain unchanged, where does density enter, and what aerodynamic tendency changes?**

# Instructor response rules

During prediction phases, avoid confirming the answer with facial expression or language. Use neutral probes such as:

- **“What makes you say that?”**
- **“Which variable changed immediately before that?”**
- **“What is your reference airflow?”**
- **“Is that a local blade force or a whole-rotor result?”**
- **“Can that quantity change if θ does not?”**
- **“What would you expect HeliLab to show if your chain is correct?”**

When correcting, correct the **broken link** in the causal chain rather than replacing the whole explanation with an instructor monologue.

# Misconception intervention map

| Misconception heard | Do not answer with | Instructor intervention |
|---|---|---|
| “Collective makes more thrust.” | “Correct, because pitch increases.” | “What changes on the blade before thrust can change?” |
| “AOA increased because pitch increased.” | immediate formula | “Could α change if θ stayed fixed?” then return to vrel |
| “Lift points upward.” | definition only | rotate/alter airflow reference and ask again |
| “The tip makes more lift.” | general confirmation | “Which term changed first as r increased?” |
| “It stalls because speed is low.” | “No.” | ask for critical AOA and separation mechanism |
| “Local lift is thrust.” | terminology correction only | force student to resolve TAF and then sum elements |

# Pilot observation sheet

During the first deliveries, an observer or instructor should capture only a few high-value metrics:

| Question | Capture |
|---|---|
| Do students commit before feedback? | yes / inconsistent / no |
| Can most students distinguish θ and α by 01:30? | approximate % |
| Can most students reason φ↑ → α↓ with θ fixed by 02:40? | approximate % |
| Does M1-04 produce explanation or slider-search behaviour? | notes |
| Which BET link causes the most failures? | velocities / angles / forces / resolution / summation |
| Is 4 h realistic? | actual timings |
| Which visual created confusion? | V-number + note |
| Exit item success | item-level approximate % |

The pilot should result in **revision evidence**, not merely “students liked it”.

---

# Fallback if HeliLab is unavailable

The pedagogical sequence must survive a technical failure. For each HeliLab activity prepare a progressive static visual with the same states:

**prediction → reveal state A → changed variable → reveal state B → explanation.**

HeliLab improves manipulation and feedback; it is not allowed to become a single point of failure for the lesson.

# Source alignment note

The current project textbook explicitly summarises BET as summed local blade-element aerodynamics, with **vr = Ωr**, induced/flight components forming **vrel**, and **α = θ − φ**. It also presents causal-chain exercises for collective increase, transition to climb and the advancing blade. Those source relationships define the technical spine of this lesson plan. The timing, prediction gates, retrieval moments, peer explanation and evidence design are instructional-design choices added by this curriculum project.
