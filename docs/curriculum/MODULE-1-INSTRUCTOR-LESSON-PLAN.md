# Module 1 — Instructor Lesson Plan

> **Pilot lesson guide · 4 contact hours including breaks and transition buffer**  
> Aerodynamic Foundations & Building Rotor Lift

This is the instructor-facing run sheet for the Module 1 prototype. It converts the curriculum design into a sequence that another instructor should be able to deliver without having designed the module themselves.

!!! warning "Pilot status"
    This is a working lesson plan. Timing and activities should be tested in a real class before they become the delivery standard. Technical explanations must remain aligned with the approved Subject 082 source material. The four-hour block is **not** treated as 240 minutes of uninterrupted instruction.

## Lesson outcome

By the end of the session, given a local blade condition or a simple **unrehearsed** changed condition, the student can independently construct and explain:

**local velocities → relative airflow → INFLOW/AOA → local aerodynamic forces → resolved components → rotor thrust / braking torque**

The central source-book practice is deliberately preserved: BET problems are reasoned through as **velocities → INFLOW/AOA → FL/FD → FV/FH → T/Mbrake**.

A student who can reproduce the words **α = θ − φ** but cannot construct the underlying velocity triangle has **not yet met the Module 1 end state**.

## Timing model

The four-hour contact block contains approximately:

- **190 minutes** planned learning activity;
- **20 minutes** protected breaks;
- **30 minutes** distributed transition, setup, overrun and discussion buffer.

The buffer is intentional. It is not spare content time to be filled with extra slides. If the lesson runs behind, protect the velocity-triangle construction, M1-04 and the final unrehearsed transfer task before optional enrichment.

## Instructor preparation

Before class, confirm that students have access to the Module 1 pre-study and prepare:

- opening/final prediction sheet;
- blank blade-element and blank velocity-triangle construction sheets or digital equivalents;
- the approved Module 1 visual sequence;
- HeliLab M1-01, M1-02 and M1-04, or static fallback visuals if a mission is not yet implemented;
- exit/transfer task;
- explanation rubric;
- timer/visible countdown for prediction tasks.

**Do not begin with a slide of learning objectives.** Begin with the helicopter problem.

# The unrehearsed transfer task

This task is the most important change from the first prototype. It prevents a student from demonstrating apparent mastery by memorising the verbal chain or repeatedly answering the same ↑/↓ relationship.

## Student receives

A **new** local blade-element state with:

- a rotor-plane/reference line;
- numerical or scaled values for **vrot** and the induced/axial component;
- a blade pitch angle **θ**;
- no pre-drawn vrel;
- no φ arc;
- no α arc;
- no force vectors.

The state must differ materially from the worked classroom example and the canonical M1-04 state.

## Student must independently

1. draw the velocity components to scale or qualitatively correct proportion;
2. construct **vrel**;
3. identify **φ** from the geometry;
4. position the blade/chord for the supplied **θ**;
5. determine **α**;
6. orient **FL** and **FD** relative to vrel;
7. construct/describe the local resultant and its normal/in-plane consequence;
8. state the expected rotor thrust/braking-torque tendency and justify it causally.

The purpose is not high-precision trigonometry. It is evidence that the student can **rebuild the model from inputs**.

## Minimum success rule for the pilot

A response cannot receive the highest formative level if the velocity triangle is absent or geometrically incoherent, even when the final ↑/↓ tendency happens to be correct.

# Instructor visual sequence

The lesson should be built around a small set of reusable figures rather than a conventional high-slide-count lecture deck.

| Visual | Purpose | Reveal strategy |
|---|---|---|
| **V01 Stable hover + collective input** | opening problem | show aircraft/context only |
| **V02 Air has mass / force bridge** | air inertia | simple conceptual visual |
| **V03 q = ½ρv² relationship** | velocity/density force dependency | reveal after prediction |
| **V04 Local aerofoil reference frame** | chord + vrel | build progressively |
| **V05 θ versus α** | misconception correction | overlay θ, then α |
| **V06 FL / FD / TAF** | force geometry | vectors appear sequentially |
| **V07 CL vs α / separation** | stall mechanism | brief bridge only |
| **V08 Rotor radial stations** | need for blade elements | compare root/outboard |
| **V09 vrot = Ωr** | rotational velocity | animate radial dependency if possible |
| **V10 Velocity triangle** | vrel + φ | **construct from blank frame; never begin completed** |
| **V11 α = θ − φ** | BET angle relationship | derive from V10 geometry |
| **V12 Section-force resolution** | local normal/in-plane components | show TAF then components |
| **V13 Local → whole rotor** | summation | repeated blade elements → Σ |
| **V14 Complete BET causal chain** | integration | students supply missing nodes |
| **V15 Original vs revised hover explanation** | conceptual change | end comparison |

**Production rule:** V04–V14 must share the approved BET Visual/Physics Contract across handbook, book-derived figures, SVG/media and HeliLab. A complete horizontal mirror is acceptable only when the entire geometry is mirrored coherently.

# Exact core prompts

### P1 · Opening
> **The helicopter is established in a stable hover. Rotor RPM remains constant. The pilot raises collective. At one blade element, what changes first — and what happens next?**

### P2 · Velocity dependency
> **If local relative-airflow speed doubles while density, area and aerodynamic coefficients are held fixed, what happens to the aerodynamic-force tendency? Commit before calculating.**

### P3 · AOA distinction
> **Can AOA change while blade pitch remains constant? If yes, what must have changed?**

### P4 · Rotor radial dependency
> **At constant rotor angular speed, which blade element has the greater rotational velocity: one near the root or one farther outboard? Explain without using the lift equation yet.**

### P5 · Inflow construction
> **Blade pitch θ remains constant and the induced/axial component changes. Redraw the velocity triangle. What happens to φ and therefore α?**

### P6 · End-of-module transfer
> **Here is a new vrot, axial-flow and θ state. Build the local aerodynamic picture from the reference plane outward. Do not use the completed BET diagram.**

# Instructor response rules

During prediction phases, avoid confirming the answer with facial expression or language. Use neutral probes such as:

- **“What makes you say that?”**
- **“Which vector did you construct first?”**
- **“What is your reference airflow?”**
- **“Where does your φ come from geometrically?”**
- **“Is that a local blade force or a whole-rotor result?”**
- **“Can that quantity change if θ does not?”**
- **“What would you expect HeliLab to show if your chain is correct?”**

When correcting, correct the **broken link** in the causal chain rather than replacing the whole explanation with an instructor monologue.

# Misconception intervention map

| Misconception heard | Do not answer with | Instructor intervention |
|---|---|---|
| “Collective makes more thrust.” | “Correct, because pitch increases.” | “What changes on the blade before thrust can change?” |
| “AOA increased because pitch increased.” | immediate formula | “Could α change if θ stayed fixed?” then return to vrel |
| “Lift points upward.” | definition only | alter airflow reference and ask again |
| “The tip makes more lift.” | general confirmation | “Which term changed first as r increased?” |
| “It stalls because speed is low.” | “No.” | ask for critical AOA and separation mechanism |
| “Local lift is thrust.” | terminology correction only | force student to resolve the resultant and then sum elements |
| “φ goes up because the formula says so.” | accept memorised rule | remove the formula and require the velocity triangle |

# HeliLab evidence boundary

For the initial pilot, HeliLab is a **learning and formative-thinking tool**, not the formal system of record.

- M1-04 may require structured prediction/causal selections before reveal.
- Session-state feedback is sufficient for the pilot.
- Optional free text may support reflection, but HeliLab does not need to score natural-language explanations.
- No LMS-style persistence, instructor dashboard or formal evidence store is required for Module 1 pilot approval.
- Formal controlled assessment remains outside HeliLab unless a later architecture decision explicitly changes this.

---

# Fallback if HeliLab is unavailable

The pedagogical sequence must survive a technical failure. For each HeliLab activity prepare a progressive static visual with the same states:

**prediction → reveal state A → changed variable → reveal state B → explanation.**

For M1-04, the fallback must still require the student to construct the velocity triangle rather than merely inspect a completed figure.

# Source alignment note

The current project textbook explicitly summarises BET as summed local blade-element aerodynamics, with rotational velocity, induced/flight components forming local relative airflow, and **α = θ − φ**. Those relationships define the technical spine of this lesson. The timing, prediction gates, retrieval moments, peer explanation and evidence design are instructional-design choices added by this curriculum project.
