# ATPL(H) Learning Ecosystem — Curriculum & Design Handbook

## Purpose

This is the master design document for the 32-hour ATPL(H) Principles of Flight course and the wider learning ecosystem around it. It is intended to be visual-first, decision-oriented, and detailed enough to guide instructors, content designers, software developers and assessment authors.

Target length: approximately 80 pages in the first complete edition.

Design rule: **diagram first, explanation second**.

# Visual design philosophy

The handbook should feel closer to an aviation systems design handbook than to an academic thesis.

Rules:
- Every chapter opens with a one-page visual summary.
- Prefer one strong diagram over 500 words.
- Text explains decisions and limitations; it does not repeat the diagram.
- Use consistent iconography and flow syntax.
- Use the institutional visual identity where appropriate.
- Keep technical diagrams editable at source.
- Separate regulatory traceability tables from the main visual narrative.
